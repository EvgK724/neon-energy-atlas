# Энергия мира — атлас стран

[Открыть приложение](https://evgk724.github.io/neon-energy-atlas/) · [Источники и определения](DATA-SOURCES.md) · [Обновление и эксплуатация](MAINTENANCE.md)

Тёмная неоновая PWA для iPhone/iPad: масштабируемая карта, одновременно включаемые показатели стран, независимые рейтинги, общий индекс, прогнозы, сравнение с Солнцем и космические проекты. В Safari: «Поделиться» → «На экран Домой». Для push откройте установленный атлас → Ещё → Обновления → Включить уведомления. На каждом устройстве разрешение выдаётся отдельно.

![QR приложения](docs/assets/qr.png)

Кнопка **Aa** в верхней панели: обычный, крупный и очень крупный текст (100%, 125%, 150%). Настройка сохраняется на устройстве и действует на подписи карты. Дробные показатели в интерфейсе округляются до десятых; исходные данные и расчёты сохраняют полную точность.

## Что считается

- **ЦОД**: функциональные объекты открытого каталога OpenStreetMap. Отдельный OSM ID — точка, здание или территория. Это НЕ полный национальный реестр и НЕ число независимых кампусов. Стройки считаются отдельно, отсутствие наблюдений — null.
- **Электроэнергия**: годовая выработка Ember в ТВт·ч; точный год виден в карточке. Рейтинг по умолчанию использует последний полный мировой год из текущей выгрузки (сейчас 2025). Мир — самостоятельный итог источника, не сумма стран разных лет.
- **АЭС**: энергоблоки IAEA PRIS In Operation; Under Construction отдельно. Статус не означает генерацию именно сейчас.
- **5G**: доля населения страны в зоне покрытия, GSMA; отдельная мировая оценка ITU. Не площадь и не количество SIM.

Карта, таблицы и рейтинг используют один JSON. Числа больше не означают количество маркеров или групп станций. Подписи располагаются для читаемости внутри вида карты, а не на площадках инфраструктуры.

Индекс атласа — среднее четырёх нормированных компонентов, каждый весом 25%. Для выработки/ЦОД/блоков используется ln(1+x)/ln(1+max), для 5G — процент. Нужны все четыре показателя; годы выработки и 5G указаны в методике индекса. Это не официальный рейтинг развития и зависит от полноты OSM.

## Обновление

GitHub Actions выполняет проверку каждые 14 дней (опорная дата 25.10.2026, 05:00 UTC / 10:00 Екатеринбург). Недельный запуск пропускает промежуточные недели. Расписание GitHub может запускаться с задержкой. Стандартный Linux runner публичного репозитория; дополнительные платные AI API не используются.

Статистика обновляется автоматически и проходит проверки. Для прогнозов проверяются числовые фрагменты доступных первичных страниц; изменённые/недоступные материалы отмечаются для сверки. Новый смысл прогноза нельзя надёжно восстановить из изменения HTML, поэтому непроверенные сценарии не заменяют проверенные значения. Полностью автономная исследовательская задача ChatGPT Work в этом аккаунте недоступна.

Push-сервер: Supabase Edge Function `atlas-push`, проект `wgkifqdgdvwfyvbzwytv`, регион Frankfurt, бесплатный тариф. Подписки и секретный VAPID-ключ находятся в закрытых таблицах; в публичном репозитории только открытый ключ. Сервер проверяет опубликованный журнал уведомлений каждые 10 минут и не повторяет отправленные ID. Никакой гарантии доставки push конкретным устройством нет: она зависит от разрешения, ОС, сети и доступности бесплатного сервиса. Бесплатный проект может быть приостановлен провайдером при неактивности; статус доступности нужно проверять в Supabase.

## Локальная проверка

```sh
python3 -m http.server 8769 --directory docs
python3 scripts/update_data.py             # только расчёт/отчёт, не изменяет опубликованный JSON
python3 scripts/update_data.py --write     # обновить снимок
python3 scripts/monitor_forecasts.py
python3 scripts/test_data.py
node scripts/test_metrics.cjs
python3 scripts/build.py
```

Для браузерной проверки нужен Playwright: `node scripts/verify.cjs http://127.0.0.1:8769`.

Исходный код — MIT. Данные OSM — ODbL 1.0, © OpenStreetMap contributors; прочие данные имеют собственные условия. См. DATA-SOURCES.md.

## Ресурсы, космос и устройства

В панели «Слои» доступны 12 совместимых переключателей. Новые: добыча нефти, запасы нефти, добыча золота, запасы золота, пусковые попытки, спутники на орбите Земли, доступность Starlink и активная база iPhone. Включение слоя переносит на него окраску карты; ранее включённые показатели остаются в подписях и карточке. Отдельные рейтинги находятся в разделе «Рейтинг». Размеры текста 100/125/150% сохраняются, дробные значения показаны до десятых.

| Метрика | Определение и доступный период | Источник |
|---|---|---|
| Добыча нефти | Средняя за 2025 год, млн баррелей/сутки; сырая нефть с промысловым конденсатом | EIA International API |
| Запасы нефти | Оценка на 01.01.2026, млрд баррелей; включает NGL и нефтяные пески; выборка 15 стран | Oil & Gas Journal |
| Добыча золота | Оценка первичной добычи за 2025 год, т/год; 13 стран отдельно | USGS MCS 2026 |
| Запасы золота | Экономически извлекаемое золото в недрах, т; выпуск USGS 2026, точная дата колонки не указана | USGS MCS 2026 |
| Пуски | Уникальные орбитальные и дальние пусковые попытки за 2025 год; отдельно 2026YTD | GCAT, J. McDowell |
| Спутники | Полезные нагрузки в свободном полёте на орбитах Земли, включая неактивные; по стране владельца | GCAT Current Object Catalog |
| Starlink | Общестрановой статус услуги; мировое число доступных рынков, отдельно аппараты и линии сервиса | Starlink, GCAT, SpaceX |
| iPhone | Более 1 млрд активных устройств за 2025 год — опубликованная нижняя граница | Counterpoint |

Рейтинг запасов нефти ограничен 15 странами; оба рейтинга золота —13 странами исходной таблицы. Неизвестные страны не заполнены нулями. Starlink показывает группы статусов без выдуманных числовых мест. Национальный рейтинг iPhone недоступен: сопоставимой открытой таблицы активных устройств нет. Продажи и веб-трафик не используются вместо количества телефонов. Прежний общий индекс сохраняет четыре исходные составляющие по 25%.

Сумма спутников стран дополняется исторической и международной атрибуцией до мирового итога; исторические аппараты СССР не присвоены России. Каталог GCAT включает определённые пограничные испытания в пусковые попытки; число попыток не является числом успешных запусков. Золотые резервы банков не относятся к минеральным запасам. Из-за разных определений нефтяных рядов отношение запасов OGJ к добыче EIA не рассчитывается.

Новые адаптеры: `scripts/extra_sources.py`, `resource_sources.py`, `space_sources.py`. Для чтения PDF нужен `pypdf==6.10.0`; GitHub Actions устанавливает его только при обновлении источников. UI-проверка новых тем: `node scripts/verify_topics.cjs URL` (Playwright Chromium/WebKit).
