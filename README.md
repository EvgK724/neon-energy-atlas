# Энергия мира · Неоновый атлас

**[Открыть приложение](https://evgk724.github.io/neon-energy-atlas/)** · [QR-код](https://evgk724.github.io/neon-energy-atlas/assets/qr.png)

Адаптивное приложение для iPhone, iPad и компьютера: тёмная карта мировой энергетики, инфраструктуры вычислений и связи. Интерфейс на русском языке.

## Возможности

- Масштабирование двумя пальцами, перетаскивание, кнопки +/−, возврат ко всему миру и разворот карты.
- Независимые слои: электрогенерация, дата-центры, 5G и атомная энергетика. Все четыре могут быть включены одновременно.
- 5 002 объекта OpenStreetMap с исходными координатами узлов или центрами контуров зданий/площадок; 4 964 показаны в начальном фильтре. Россия — 79 точек, Китай — 121.
- 208 точек GEM, относящихся к 196 проектам АЭС: 424 блока в эксплуатационном статусе, 85 в строительстве. Приблизительные координаты отмечены отдельно.
- Группировка близких точек, фильтры статусов, поиск по названию/городу/оператору и карточки объектов со ссылками на источники.
- Статистика стран и мира, сравнение с Солнцем, прогнозы и космические проекты.
- Сохранение выбранных слоёв, страны и положения карты на устройстве.
- Установка на домашний экран; сохранённые интерфейс, данные и обзорные границы работают без сети. Подробные улицы и внешние ссылки требуют интернета.

## Установка на iPhone и iPad

1. Откройте [приложение](https://evgk724.github.io/neon-energy-atlas/) в Safari.
2. Нажмите «Поделиться» → «На экран “Домой”».
3. Если предлагается, включите «Открывать как веб-приложение», затем нажмите «Добавить».

Это устанавливаемое веб-приложение (PWA). Ориентация экрана не заблокирована. Адаптация под iPhone 18 Pro Max выполнена по размеру окна, без привязки к названию модели или User-Agent. Проверка в браузерных движках не заменяет проверку на физическом устройстве.

## Данные и ограничения

Снимок подготовлен 11 октября 2026 года. У разных слоёв разные даты и определения; подробная методика доступна в приложении через «О проекте» и в [DATA-SOURCES.md](DATA-SOURCES.md).

Точки ЦОД не являются полной переписью: один кампус может иметь несколько отдельных зданий в OSM. Число точек нельзя сравнивать напрямую с национальными итогами Data Center Map. Аналогично 208 точек АЭС не означают 208 отдельных станций; реестровые статусы не показывают текущую выработку в реальном времени. Границы 5G кодируют долю населения страны, а не географию радиопокрытия.

## Локальный запуск и выпуск

Зависимости браузера включены в `docs/vendor`; сборщик JavaScript не требуется.

```sh
python3 scripts/build.py
python3 -m http.server 8000 --directory docs
```

Откройте `http://localhost:8000/`. Сборка рассчитывает версию по содержимому файлов и генерирует service worker. При обновлении меняется имя кэша; новая версия активируется после закрытия всех окон прежнего приложения, чтобы не прерывать просмотр.

GitHub Pages: ветка `main`, папка `/docs`. Никаких API-ключей, аккаунтов приложения, аналитики или серверного хранилища не требуется.

Файлы `docs/data/datacenters.json` и `docs/data/nuclear.json` содержат данные, происхождение, лицензию и правила преобразования. OpenStreetMap-тайлы загружаются только для видимой области на близком масштабе, не сохраняются service worker и не скачиваются пакетами.
